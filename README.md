## 💻 Lively Wallpaper'da Nasıl Kullanılır?

1. Bilgisayarınızda **Lively Wallpaper** uygulamasını açın.
2. Sol menüden **+ (Duvar Kağıdı Ekle)** butonuna tıklayın.
3. **URL Girin** alanına şu linki yapıştırın:
   ```text
   https://sytali0.github.io/cozy-anime-room/
   ```
4. **İleri / Tamam** diyerek duvar kağıdı olarak ayarlayın.
5. Masaüstünüzde kedinin üzerine tıklayarak **Tokyo** ve kalpli baloncukları test edin!
